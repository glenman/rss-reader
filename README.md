# Glenman 阅读器 - RSS Reader

一个简洁、现代、支持多主题的 RSS 阅读器 Web 应用。专注于阅读体验，提供气泡式热点概览、侧边栏订阅管理、以及灵活的主题切换功能。

![GitHub](https://img.shields.io/badge/GitHub-glenman%2Frss--reader-blue)

---

## ✨ 功能特色

### 📖 核心功能
- **多源订阅**：支持添加、删除多个 RSS 订阅源
- **分类管理**：按主题分类组织订阅源，便于查找和管理
- **实时刷新**：一键刷新所有订阅源，获取最新文章
- **本地存储**：所有数据保存在浏览器 LocalStorage 中，无需后端

### 🎨 界面与交互
- **气泡式热点**：首页以动态上升气泡展示最新未读文章，点击即可查看详情
- **自动折叠侧边栏**：鼠标离开自动收起，节省阅读空间
- **智能搜索**：支持订阅源搜索和文章标题搜索，快速定位内容
- **流畅动画**：侧边栏折叠、气泡上升、切换主题等多处平滑动画

### 🌈 四种主题模式
| 主题 | 风格 | 适用场景 |
|------|------|---------|
| ☀️ **日间模式** | 白底黑字 | 光线充足环境，清晰度高 |
| 🌙 **夜间模式** | 深灰背景+柔和白字 | 暗光环境，减少眩光 |
| 🍃 **护眼模式** | 豆沙绿底深色字 | 长时间阅读，缓解视疲劳 |
| 📜 **纸质模式** | 米白浅棕底深色字 | 模拟纸张，复古温馨 |

---

## 🛠️ 技术栈

- **前端**：纯 HTML5 + CSS3 + 原生 JavaScript（零依赖）
- **数据来源**：RSS 2.0 / Atom（通过公共 API 转换）
- **存储**：浏览器 LocalStorage
- **部署**：GitHub Pages（静态托管）

## 🚀 快速开始

### 方式一：在线使用
已部署至 GitHub Pages，直接访问：
```
https://glenman.github.io/rss-reader/
```

### 方式二：本地运行

```bash
# 克隆仓库
git clone https://github.com/glenman/rss-reader.git

# 进入项目目录
cd rss-reader

# 启动本地服务器（需要 Python）
python -m http.server 8000

# 浏览器打开
# http://localhost:8000
```

> 也可以使用任何静态服务器（如 `npx serve`、`php -S`、VSCode Live Server 等）

## 📖 使用指南

### 添加订阅源
1. 鼠标悬停左侧边栏或点击左上角展开
2. 点击 **+** 按钮
3. 输入 RSS 地址（如 `https://example.com/rss`）
4. 选择或创建分类
5. 点击确认

### 阅读文章
1. 首页气泡展示最新未读热点，直接点击气泡进入文章详情
2. 或从侧边栏选择订阅源，在中间区域浏览文章列表
3. 点击文章标题，右侧显示完整内容
4. 点击详情页关闭按钮返回列表

### 切换主题
点击顶部主题按钮（☀️ 🌙 🍃 📜）即可一键切换，设置会自动保存。

### 搜索
- **左侧搜索框**：搜索订阅源名称
- **顶部搜索框**：搜索当前订阅源下的文章标题

## 🎯 设计理念

1. **零依赖**：不使用任何 JavaScript 框架或构建工具，打开即用
2. **离线优先**：数据存储在本地，无账号、无云端、无追踪
3. **阅读为中心**：专注于内容阅读体验，减少无关干扰
4. **轻量级**：单 HTML 文件，加载速度快，资源占用低
